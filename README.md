# 🕸 LangGraph — Darslarim

**LangGraph** framework'ini o'rganish bo'yicha darslar va namunalar (grafik, routing, tools, workflow).

---

## ✨ Mavzular

- 📓 **day1–day4.py** — asosiy tushunchalar
- 🔀 **routing_graph.ipynb** — shartli o'tishlar
- 🛠 **tools_graph.ipynb** — tool integratsiyasi
- 🔄 **workflow.ipynb** — ish oqimi
- 🧭 **orchestrater_flow.ipynb** — orkestratsiya
- 💬 **messages.ipynb** — xabarlar bilan ishlash

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **LangGraph** | Agent grafiklari |

## ⚙️ O'rnatish

```bash

```
